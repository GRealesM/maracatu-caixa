    Notation guide

    One line per bar, 16 sixteenths. Spaces are ignored, so group them by beat. A line starting with # starts a new groove and gives its name.

    # Baque de Afoxé
XooX Xooo oXoX Xooo
XooX Xooo oXoX XoXo
XooX Xooo oXoX Xooo
XoXo XoXo X... ....

# Martelo
XXoX XoXo XXoX XoXo | RRLR RLRL RRLR RLRL

# Sandrinho break
X..X ..X. .X.. X.X.  x2
~~~~ ~~~~ X..X X... | B... .... F..F B...

    Notes: X head, o ghost, . rest, ~ rumble. Add x2, x3… at the end of a line to repeat that bar.

    Sticking (optional, after a |; without it hands alternate R L R L):

    R Lright or left hand
    r lRR or LL: a double stroke inside one box (two 32nds)
    Bboth sticks together
    Fflam: a soft grace note just before the main stroke
    .no sticking shown

    Apply text in “This groove” replaces the current groove. In “All grooves”, grooves are matched by name: the same name updates it, a new name adds a groove. Apply never deletes. Lines starting with // are comments.

    Import file accepts this app’s export, the old backup JSON, or a .txt in this notation, and merges the same way.
